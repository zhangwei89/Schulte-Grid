# 🎯 舒尔特方格 (Schulte Focus Master)

> **极简、流畅、高颜值的专注力与周边视野（余光）速度训练网页游戏**  
> 纯原生 Vanilla JS 开发 · 零外部网络依赖 · 毫秒级反馈 · 即开即玩 · 支持 GitHub Pages 一键部署

---

## 📖 简介与科学原理

**舒尔特方格（Schulte Table）** 是由心理学家瓦尔特·舒尔特（Walter Schulte）发明的经典注意力测验法。其最初用于神经心理学上注意力分配与广度的测定，后来被广泛应用于**飞行员选拔、专业运动员视觉反应拓展及快速阅读（速读）视野训练**。

### 核心训练法则
- **练“余光”，不练“转眼珠”**：训练时双眼自然注视方格正中央锚点，保持头部与眼球平稳，尽量避免视线频繁大幅跳跃。
- **扩大周边视野（Peripheral Vision）**：通过边缘余光捕捉周围目标，在定位当前目标的同时预判下一目标，形成连续的视读节奏。
- **选中反馈与原色恢复**：当前选中的数字变色高亮；当选择下一个目标文字时，前一个方格立即恢复其原始颜色与样式，保持整盘完整的视觉干扰，充分激发视敏度。

## ✨ 核心特性

- 📐 **全规格矩阵挑战**
  - **3×3** (9格 · 儿童/新手入门)
  - **4×4** (16格 · 进阶热身)
  - **5×5** (25格 · 国际标准测评规格)
  - **6×6** (36格 · 高级挑战)
  - **7×7** (49格 · 大师级视野扩展)

- 🎮 **五大训练模式**
  - **正序挑战** (1 → N)：标准搜索训练。
  - **倒序挑战** (N → 1)：打破惯性思维，双重负荷认知。
  - **记忆消隐**：点击过的方格渐隐消失，强化短时记忆。
  - **色彩干扰**：各方格随机高对比度色彩，考验色彩过滤与抗干扰感知。
  - **动态微移**：每次成功点击随机微移位置，考验动态视觉抓取。

- 🔠 **多字符体系支持**
  - **阿拉伯数字**：1, 2, 3...
  - **中文简体数字**：一, 二, 三...
  - **中文大写数字**：壹, 贰, 叁... (防伪金融/高难度汉字辨析)
  - **英文字母**：A, B, C...

- 🎯 **精准交互与视觉规则**
  - **单目标聚焦**：当前选中的方格高亮发光变色；选定下一个目标时，上一个方格**即刻恢复原有颜色**。
  - **防误触震颤**：点错时触发震颤动画与错误音效，支持开启 +1.00s 误触时间惩罚。
  - **中心锚点**：配备可开关的中央视线聚焦红点，辅助视线定格。

- 📊 **科学评级与数据分析**
  - **段位评级**：基于国际标准的 SSS（宇航员/速读级）、SS、S、A、B 评级。
  - **每格反应节奏图（Pace Chart）**：毫秒级柱状图可视化展示每一步搜寻耗时，定位注意力薄弱间歇。
  - **战绩留存**：自动记录各规格个人历史最佳（PB）及最近训练明细，支持一键清空与战报剪贴板分享。

- 🎨 **极致界面与多维主题**
  - **深浅模式**：适配暗黑（Dark）与浅色（Light）模式。
  - **多款色系**：极光靛蓝 (Indigo)、森境翡翠 (Emerald)、晚霞绯红 (Rose)、琥珀金芒 (Amber)、赛博极客 (Violet)。
  - **合成音效 & 粒子特效**：基于 Web Audio API 实时生成清脆音效（无需下载音频文件），通关自动绽放 Canvas 烟花彩屑。

## 🚀 本地运行

该项目为纯静态单页应用，**零外部依赖、无需构建工具、无需安装 npm 包**。

1. **直接双击运行**：
   下载代码后，使用任意现代浏览器（Chrome、Edge、Safari、Firefox）双击打开 `index.html` 即可畅玩。

2. **本地静态服务（可选）**：
   ```bash
   # 使用 Python 启动本地服务
   python -m http.server 8080
   # 浏览器访问 http://localhost:8080
   ```

## 🌐 部署至 GitHub Pages

本项目已完全适配 GitHub Pages 静态托管：

1. 将代码推送到 GitHub 仓库（主分支 `main` 或 `master`）。
2. 在仓库页面点击 **Settings** → **Pages**。
3. 在 **Build and deployment** 下将 **Source** 设为 `Deploy from a branch`。
4. **Branch** 选择 `main`（或 `master`），目录保持 `/ (root)`，点击 **Save**。
5. 稍等 1-2 分钟，即可通过 `https://<用户名>.github.io/<仓库名>/` 全球公网访问。
